# Match Predictor — Design Spec

**Date:** 2026-06-03  
**Status:** Approved

---

## Overview

A Streamlit web app that predicts the result (and probabilities) of a football match using a Random Forest classifier trained on historical match data from Kaggle.

**Inputs:** Two teams (home and away), selected from a dropdown.  
**Outputs:** Predicted result (Home Win / Draw / Away Win) + probability bar chart.

---

## Architecture

Three independent layers:

```
data/results.csv
      ↓
src/preprocess.py   — cleans raw CSV, engineers features per team
src/train.py        — trains RandomForestClassifier, saves model.pkl
src/predict.py      — loads model.pkl, builds feature vector, returns prediction + probabilities
      ↓
app.py              — Streamlit UI
```

**Data flow:**
1. User downloads CSV from Kaggle and places it in `data/`
2. `preprocess.py` computes rolling features per team over their last 5 matches
3. `train.py` trains the model and serializes it as `model.pkl`
4. In the app, user selects home and away teams → `predict.py` builds feature vector → returns result + probabilities displayed as a horizontal bar chart

---

## Dataset

**Source:** [International football results from 1872 to 2023 (Kaggle)](https://www.kaggle.com/datasets/martj42/international-football-results-from-1872-to-2017)

**Columns used:** `date`, `home_team`, `away_team`, `home_score`, `away_score`, `tournament`, `neutral`

---

## Features

For each match to predict, the following features are computed from each team's last 5 matches:

| Feature | Description |
|---|---|
| `home_avg_goals_scored` | Avg goals scored by home team (as home) |
| `home_avg_goals_conceded` | Avg goals conceded by home team (as home) |
| `away_avg_goals_scored` | Avg goals scored by away team (as away) |
| `away_avg_goals_conceded` | Avg goals conceded by away team (as away) |
| `home_win_rate` | Win rate of home team in last 5 matches |
| `away_win_rate` | Win rate of away team in last 5 matches |
| `home_is_neutral` | Whether the match is on a neutral ground (0/1) |

**Target label:** `result` → `H` (home win), `D` (draw), `A` (away win)

---

## Model

- **Algorithm:** `sklearn.ensemble.RandomForestClassifier`
- **Output:** Predicted class + `predict_proba` for all three classes
- **Serialization:** `joblib.dump` → `model.pkl`
- **Training/test split:** 80/20 chronological (no random shuffle to avoid data leakage)

---

## Streamlit UI

Single-page app:

1. **Dropdowns** — home team and away team (populated from unique teams in dataset)
2. **Predict button** — triggers prediction
3. **Result display** — most likely outcome in large text
4. **Probability chart** — horizontal bar chart (Plotly or st.bar_chart) with percentages
5. **Warning** — if either team has fewer than 5 historical matches in the dataset

## Error Handling

- If `model.pkl` doesn't exist, `app.py` shows instructions to run `train.py` first
- If a team has < 5 matches in history, show a warning but still predict with available data
- If selected teams are identical, show a validation error

---

## Out of Scope

- Live data / API integration
- Exact score prediction
- League-specific models
- User accounts or persistence
